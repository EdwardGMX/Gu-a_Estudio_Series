## 🌊 Unidad II · Modelos MA solos {#u2-ma}
@mapa El MA(1) estimado y por qué no alcanza, los momentos del MA, la ACF que se corta en q, cuántos términos haría falta, cómo pronostica un MA, la invertibilidad y la comparación entre AR y MA.

:::pastilla rojo | Aplicar · El MA(1) estimado | u2:ma-def u2:ma-python {#ma-uno}
Estimar un **MA(1)**, $y_t = \mu + \varepsilon_t + \theta_1 \varepsilon_{t-1}$: el viento como la media más el choque de esta hora y una parte del choque de la hora anterior. Es el otro bloque básico de la Unidad II.
@@ Parámetros
| Parámetro | Valor | Por qué |
|---|---|---|
| `ARIMA(y_fit, order=(0, 0, 1))` | máxima verosimilitud | La forma estándar de estimar un MA. |
| ρ₁ teórica | θ / (1 + θ²) | La única autocorrelación distinta de cero de un MA(1). |
@@ Código
```python
def evaluar_sm(res, origenes=ORIGENES_VAL, transf=None, inv=None, niveles=(), exog=None):
    """Pronósticos de 24 h en cada origen con un modelo de statsmodels de parámetros fijos (predicción dinámica)."""
    fin = origenes[-1] + pd.Timedelta(hours=23)
    datos = y[:fin] if transf is None else transf(y[:fin])
    r_all = res.apply(datos) if exog is None else res.apply(datos, exog=exog.loc[:fin])
    filas = []
    for t0 in origenes:
        pr = r_all.get_prediction(start=t0, end=t0 + pd.Timedelta(hours=23), dynamic=True)
        idx = pd.date_range(t0, periods=24, freq="h")
        d = {"real": y[idx].values, "pron": pr.predicted_mean.values, "h": np.arange(1, 25)}
        for nv in niveles:
            ci = pr.conf_int(alpha=1 - nv / 100).values
            d[f"lo{nv}"], d[f"hi{nv}"] = ci[:, 0], ci[:, 1]
        df = pd.DataFrame(d, index=idx)
        if inv is not None:
            for c in [c for c in df.columns if c not in ("real", "h")]:
                df[c] = inv(df[c].values)
        df["pron"] = df["pron"].clip(lower=0)
        filas.append(df)
    del r_all
    return pd.concat(filas)

ma1 = ARIMA(y_fit, order=(0, 0, 1)).fit()
th1 = ma1.params["ma.L1"]
print(ma1.params.round(4).to_string())
print(f"\nρ₁ teórica = θ / (1 + θ²) = {th1 / (1 + th1 ** 2):.3f} | r₁ del viento = {acf_fit[1]:.3f} | máximo posible en un MA(1): 0.5")
print(f"σ del error: {np.sqrt(ma1.params['sigma2']):.3f} m/s (AR(1): {np.sqrt(ar1.sigma2):.3f})")
VAL["MA(1)"] = evaluar_sm(ma1)
print(f"MAE en la validación: {metricas(VAL['MA(1)']['real'], VAL['MA(1)']['pron'])['MAE']:.3f}")
```
@@ Lectura
- θ̂ = {{=th1|.3f}}, y con él la autocorrelación teórica a una hora es {{=th1 / (1 + th1 ** 2)|.3f}}: casi el **máximo posible** de un MA(1), que es 0.5. El viento tiene {{=acf_fit[1]|.2f}}.
- El error a un paso es enorme: σ = {{=np.sqrt(ma1.params['sigma2'])|.2f}} m/s, más del doble que el AR(1).
- En la validación el MAE es {{=metricas(VAL['MA(1)']['real'], VAL['MA(1)']['pron'])['MAE']|.2f}}: peor que el ingenuo y casi igual que la media histórica.
@@ Decisión
❌ Un MA(1) no puede representar una serie tan persistente: su memoria dura una sola hora.
:::

:::pastilla azul | Aplicar · Media, varianza y autocovarianzas de los MA | u2:ma-momentos u2:demo-ma-momentos {#ma-momentos}
Comprobar las fórmulas de los momentos de un MA(q): $\mu$ es la constante, $\gamma_0 = \sigma^2(1 + \theta_1^2 + \cdots + \theta_q^2)$ y $\gamma_k = \sigma^2 \sum_j \theta_j \theta_{j+k}$ para k ≤ q (cero después). Se comparan con los momentos muestrales del viento.
@@ Parámetros
| Parámetro | Valor | Por qué |
|---|---|---|
| órdenes | 1, 2, 6 y 12 | Para ver cómo cambia la varianza explicada. |
| θ₀ | 1 | La convención: el choque actual entra con peso 1. |
@@ Código
```python
MA_Q = {1: ma1}
for q in [2, 6, 12]:
    MA_Q[q] = ARIMA(y_fit, order=(0, 0, q)).fit()
filas_mm = []
for q, r in MA_Q.items():
    th = np.r_[1, r.params[[f"ma.L{j}" for j in range(1, q + 1)]].values]
    s2 = r.params["sigma2"]
    g0 = s2 * np.sum(th ** 2)
    g1 = s2 * np.sum(th[:-1] * th[1:])
    filas_mm.append({"q": q, "μ": r.params["const"], "γ₀ teórica": g0, "ρ₁ teórica": g1 / g0, "σ": np.sqrt(s2)})
tab_ma_mom = pd.DataFrame(filas_mm).set_index("q")
print(tab_ma_mom.round(3).to_string())
print(f"\nMuestral: media {y_fit.mean():.3f} | varianza {y_fit.var():.3f} | r₁ {acf_fit[1]:.3f}")
```
@@ Lectura
- La media de todos los MA es la media muestral ({{=tab_ma_mom['μ'].iloc[0]|.2f}}): en un MA, la constante **sí es** la media.
- La varianza teórica de los MA ({{=tab_ma_mom['γ₀ teórica'].min()|.0f}} a {{=tab_ma_mom['γ₀ teórica'].max()|.0f}}) es **mucho menor** que la del viento ({{=y_fit.var()|.0f}}): los MA no alcanzan a explicar la variabilidad de varios días.
- ρ₁ teórica sube con q (de {{=tab_ma_mom['ρ₁ teórica'].iloc[0]|.2f}} a {{=tab_ma_mom['ρ₁ teórica'].iloc[-1]|.2f}}) y σ baja: con más términos el MA imita mejor la persistencia, pero con 12 términos todavía tiene más error que el AR(1).
@@ Decisión
🔵 Las fórmulas se cumplen, y muestran el problema: la varianza de un MA es la de q + 1 choques sumados, y el viento acumula choques de muchos días.
:::

:::pastilla verde | Aplicar · La ACF del MA se corta en q | u2:ma-acf u2:w-ma {#ma-acf}
Calcular la ACF teórica de los MA estimados: es exactamente **cero después del rezago q**. El viento, en cambio, tiene autocorrelación a cientos de rezagos. Mueve el control para cambiar q.
@@ Parámetros
| Parámetro | Valor | Por qué |
|---|---|---|
| `ArmaProcess([1], [1, θ₁, …])` | MA(q) teórico | El polinomio θ(L). |
| q | 1, 2, 6, 12 y 24 | Hasta un día. |
@@ Código
```python
ma24 = ARIMA(y_fit, order=(0, 0, 24)).fit()
MA_Q[24] = ma24
acf_ma = {q: ArmaProcess([1], np.r_[1, r.params[[f"ma.L{j}" for j in range(1, q + 1)]].values]).acf(73) for q, r in MA_Q.items()}
for q, a in acf_ma.items():
    print(f"MA({q:>2}): ρ₁ = {a[1]:.3f}, ρ_q = {a[q]:.3f}, ρ_(q+1) = {a[q + 1]:.3f}")
```

@@ Lectura
- La ACF teórica de cada MA es **exactamente cero** después del rezago q: el MA(6) tiene ρ₇ = 0, el MA(24) tiene ρ₂₅ = 0.
- Antes de q, la ACF del MA cae mucho más rápido que la del viento: el MA(24) llega a ρ₂₄ = {{=acf_ma[24][24]|.3f}}, mientras el viento tiene {{=acf_fit[24]|.2f}}.
@@ Decisión
✅ Es el patrón de identificación de la Unidad II: el MA tiene ACF que se corta y PACF que decae. El viento tiene lo contrario: **el viento no es un MA**.

:::pastilla rojo | Aplicar · Cómo pronostica un MA: a la media en q pasos | u2:ma-def u2:arima-pronostico {#ma-pronostico}
Pronosticar con los MA en la validación. Un MA(q) solo "recuerda" los últimos q choques: después de q horas su pronóstico es **exactamente la media**. Mueve el control y mira cuándo se vuelve plano.
@@ Parámetros
| Parámetro | Valor | Por qué |
|---|---|---|
| pronóstico | dinámico desde cada medianoche | Con los parámetros estimados en `y_fit`. |
| q | 1, 2, 6, 12 y 24 | Los mismos de la ACF. |
@@ Código
```python
val_ma = {q: (VAL["MA(1)"] if q == 1 else evaluar_sm(r)) for q, r in MA_Q.items()}
mae_ma = pd.Series({q: metricas(v["real"], v["pron"])["MAE"] for q, v in val_ma.items()})
print("MAE en la validación:", mae_ma.round(3).to_dict())
print(f"AR(1), con un solo parámetro: {mae_ar[1]:.3f}")
for q in MA_Q:
    VAL[f"MA({q})"] = val_ma[q]
```

:::pastilla azul | Aplicar · Invertibilidad: dos MA con la misma ACF | u2:invertibilidad u2:demo-gemelos u2:ar-infinito {#ma-invertibilidad}
Comprobar que un MA(1) con θ y otro con 1/θ tienen **la misma ACF**: con los datos no se pueden distinguir. Se elige el **invertible** (|θ| < 1), que se puede escribir como un AR(∞) con pesos π<sub>j</sub> = −(−θ)<sup>j</sup> que se apagan.
@@ Parámetros
| Parámetro | Valor | Por qué |
|---|---|---|
| θ̂ | el del MA(1) estimado | El invertible que eligió statsmodels. |
| 1/θ̂ | su gemelo no invertible | Misma ACF, otra varianza del choque. |
@@ Código
```python
gemelo = 1 / th1
rho_a, rho_b = th1 / (1 + th1 ** 2), gemelo / (1 + gemelo ** 2)
print(f"θ = {th1:.4f} → ρ₁ = {rho_a:.4f} | θ = 1/θ = {gemelo:.4f} → ρ₁ = {rho_b:.4f}")
print(f"σ² del gemelo para tener la misma varianza: {ma1.params['sigma2'] * th1 ** 2:.3f} (el invertible: {ma1.params['sigma2']:.3f})")
print("¿Invertible?", ArmaProcess([1], [1, th1]).isinvertible, "| ¿el gemelo?", ArmaProcess([1], [1, gemelo]).isinvertible)
pi_w = ArmaProcess([1], [1, th1]).arma2ar(13)
print("Pesos del AR(∞) equivalente (π₁ a π₆):", np.round(-pi_w[1:7], 3))
```
@@ Lectura
- θ = {{=th1|.3f}} y θ = 1/θ = {{=gemelo|.3f}} dan la **misma** ρ₁ ({{=rho_a|.4f}}): con los datos no se pueden distinguir. Ajustando σ², también tienen la misma varianza.
- statsmodels eligió el **invertible**. Su forma AR(∞) tiene pesos que alternan de signo y se apagan despacio ({{=-pi_w[1]|.2f}}, {{=-pi_w[2]|.2f}}, {{=-pi_w[3]|.2f}}…), porque θ está cerca de 1.
@@ Decisión
🔵 La invertibilidad es la condición de los MA equivalente a la estacionariedad de los AR: garantiza un único modelo y que los choques se puedan recuperar de los datos.
:::
